# Web & Graphic Design for Traditional Artists — Resources

## Knowledge

- [W3C WAI: Designing for Web Accessibility](https://www.w3.org/WAI/tips/designing/)
  Practical visual-design guidance for contrast, headings, spacing, navigation, responsive viewports, and feedback. Use when a beautiful choice also needs to work for more people.
- [W3C WAI: Understanding Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
  The primary source for the 4.5:1 normal-text and 3:1 large-text contrast thresholds used in the colour lesson.
- [W3C WAI: Understanding Visual Presentation](https://www.w3.org/WAI/WCAG22/Understanding/visual-presentation)
  Readability guidance for text width, alignment, and spacing. Use when shaping reading environments rather than isolated lettering.
- [MDN: Responsive web design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design)
  A clear primary reference for fluid layout, breakpoints, and the fact that a web layout must work at many sizes.
- [web.dev: Learn Responsive Design](https://web.dev/learn/design/)
  A structured modern course on responsive layout, type, imagery, accessibility, and interaction. Use as the technical companion to the later web lessons.
- [Interaction Design Foundation: Visual hierarchy](https://www.interaction-design.org/literature/topics/visual-hierarchy)
  An accessible explanation of hierarchy, scanning, alignment, and negative space. Use to connect graphic composition to interfaces.

## Wisdom (Communities)

- [AIGA](https://www.aiga.org/)
  Professional design association with local chapters and events. Use for portfolio feedback and exposure to working designers.
- [The Design Buddies Discord](https://designbuddies.community/)
  A large peer community for design critique and career questions. Use after making a small project; ask one focused question and show the work.
