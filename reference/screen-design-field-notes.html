Screen design field notes.

Use this after the lessons: a compact set of questions for turning visual instinct into legible, usable composition.

The artist-to-screen translation

Value & focal pointUse contrast and scale to establish the first read.
Negative spaceUse gaps to separate groups and let important items breathe.
Construction drawingUse grids and shared edges to create alignment.
Line qualityUse typography roles to give text a legible voice.
Series cohesionUse reusable type, colour, spacing, and image rules as a system.
RecompositionUse responsive layouts to preserve the story across screen shapes.

Five questions before you add decoration

  1. Purpose: What is the visitor here to understand or do?
  2. Order: What should they notice first, second, and third?
  3. Groups: Which things belong together, and is the spacing making that obvious?
  4. Reading: Is type large, contrasted, and spacious enough for its role?
  5. Context: Does this still work when narrow, enlarged, or used with a keyboard?

Compact rules

  • Inside a group: smaller gaps. Between groups: larger gaps.
  • Use one primary action and give it a clear label.
  • Let repeated parts use repeated spacing and alignment.
  • Set body text for reading before setting it for mood.
  • Use value contrast first; do not rely on colour alone.
  • Test a web composition at narrow and wide widths.
  • Make interaction states and feedback visible.

Accessibility guardrails

  • Normal-size text: aim for at least 4.5:1 contrast; large text: at least 3:1. W3C source
  • Do not force text to remain fixed when users enlarge spacing or type.
  • Do not use colour as the only difference between meaningful states.
  • Design changes at the point content becomes cramped, not merely at named device sizes.
