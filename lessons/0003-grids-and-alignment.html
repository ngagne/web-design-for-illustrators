15–20 minutes · Structure

Give it invisible bones.

A grid is a set of shared edges and intervals that lets a composition feel deliberate before the viewer can explain why.

Skill: align a small page to a simple grid

Translate what you already know.

From drawingGesture, construction lines, and perspective establish a stable world underneath expressive marks.
On a screenA grid gives text, images, controls, and margins common reference lines. It creates rhythm without requiring every item to be identical.

One idea

Alignment communicates relationship. If two elements share an edge, the eye assumes they belong to the same system. Start with one wide content column and a small set of repeated gaps; add columns only when the content demands them.

Primary source: Material Design’s responsive layout examples.

Retrieval check

Which tool gives repeated elements shared edges and intervals?

Make a four-line grid.

  1. On paper, mark a left and right margin.
  2. Draw two faint vertical guides inside them.
  3. Place a title, image box, description, and button so their edges reuse those guides.
  4. Erase the guides. If the arrangement falls apart, align two more edges rather than adding a decorative rule.

Ask your teacher where the grid is helping and where it is making the composition too rigid.

Remember

Use a grid as a construction drawing: it supports expression; it does not replace judgment.
