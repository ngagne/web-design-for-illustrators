20–25 minutes · Web-specific

The canvas changes shape.

A web composition is not one frozen rectangle. It reflows across narrow, wide, tall, and touch-driven situations.

Skill: preserve hierarchy when a layout becomes narrow

Translate what you already know.

From illustrationYou recompose a scene when it must fit a different crop or print ratio, protecting the story’s essential relationships.
On the webYou decide what stacks, shrinks, wraps, reorders, or disappears when there is less room—without sacrificing purpose or access.

One idea

Start with the narrow layout. It forces a decision about what is essential. When the page gains width, add columns or supporting detail only when the content has room to breathe. Break at a content failure, not at a fashionable device size.

Primary source: MDN’s responsive web-design guide.

Retrieval check

What is a common first move when two columns no longer have room?

Make two thumbnails, not one.

  1. Draw your page wide, with all essential content.
  2. Draw it again as a narrow phone screen.
  3. Stack related columns, keep the primary action visible, and shorten navigation if necessary.
  4. Compare the two: can a visitor still name the page purpose and next action?

Ask your teacher to review both thumbnails side by side. A responsive decision is only clear when both contexts are visible.
